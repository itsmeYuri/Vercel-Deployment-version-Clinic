# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Patients, doctors, laboratory staff, and administrators use role-specific clinic workflows. Public visitors can review published laboratory test bundles before signing in.

## Product Purpose
The centralized laboratory system manages laboratory requests, results, facilities, and patient access. The public landing page introduces the system and displays administrator-managed laboratory test bundles.

## Capabilities and Constraints
The existing application uses PHP, server-side database access, and Supabase PostgreSQL in deployment. Administrators manage test definitions. Laboratory test bundles are a separate public catalogue and must use existing test definitions. Existing authentication and clinical result workflows remain in place.

## Brand Commitments
Use the existing clinic name and logo asset. Pricing and package contents come from administrator-entered data; no invented offers or medical claims.
